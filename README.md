An e-learning web application developed during my Software Developer internship at TechCiti Software Consulting Private Limited, Bengaluru.

## Project Context

- Internship: 7 May–10 June 2025
- Domain: Python web development

## Overview

The project involved developing a web application for accessing online learning resources, with user registration, authentication and personalised dashboard functionality.

## Application Workflow

1. A visitor opens the home page.
2. A new user registers through a form.
3. The application validates the submitted information.
4. A registered user logs in.
5. The authenticated user accesses their dashboard.
6. Django views, templates and database models support these interactions.
